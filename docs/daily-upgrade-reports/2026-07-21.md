# AI팀 일일 업그레이드 보고 — 2026-07-21

## 🔍 벤치마킹 인사이트

1. **Agentic AI의 자동화 루프**: 2026년 선도 공장들은 단순 알림 수준을 넘어, AI 에이전트가 이상 감지 → ERP 부품 재고 조회 → 기술자 배정 → 작업지시서 생성까지 인간 개입 없이 처리하는 'Prescriptive Maintenance' 체계를 운영 중이며, ROI 달성까지 평균 3~6개월 소요.

2. **OEE 격차 심화**: 2023~2024년에 AI 예측 정비 소프트웨어를 도입한 제조사들이 달력 기반 정비를 유지하는 경쟁사 대비 OEE(Overall Equipment Effectiveness) 15~20% 우위를 기록. 도입 지연이 곧 경쟁력 손실로 직결됨.

3. **Multi-Agent + MCP 아키텍처 표준화**: 2026년 산업 AI 표준은 단일 모델이 아닌, A2A(Agent-to-Agent) 프로토콜로 역할별 전문 에이전트가 협업하고 MCP(Model Context Protocol)로 실시간 데이터 소스에 연결하는 분산 구조로 수렴 중.

4. **자동차 부품 분야 예측 정비 ROI**: AI 예측 정비 적용 시 다운타임 최대 50% 감소, 에너지 소비 25% 절감, 탄소 배출 30% 감소 효과가 보고됨. ECU 및 온보드 센서 데이터 스트림 분석이 핵심 기술로 자리잡음.

5. **워크플로우 자동화 재무 효과**: 중소 제조사들이 예방 가능한 워크플로우 비효율로 연간 평균 $340,000 손실. 체계적 자동화 도입 시 12개월 내 납기 준수율 18~34% 개선 달성 사례 다수.

## 🟢 팀원별 업그레이드 제안

### translator
- **개선 제안**:
  - 한↔영 번역 시 제조 도메인 용어 일관성을 보장하는 **전문 용어 사전(glossary) DB**를 Supabase 테이블로 구축. AI가 번역 전 용어집을 참조하도록 프롬프트 체인 적용.
  - 본사-인도 커뮤니케이션 문서에 **번역 품질 자동 검수 레이어** 추가: 역번역(back-translation) 비교로 의미 손실 탐지.
  - 회의록, 보고서, 기술 매뉴얼 등 문서 유형별로 번역 톤/포맷 템플릿 분리 운영.
- **적용 우선순위**: 🔴 용어 사전 DB 구축 → 🟡 문서 유형별 템플릿 → 🟢 역번역 검수

### data-analyst
- **개선 제안**:
  - Excel/CSV 수동 업로드 의존도 줄이기: **Supabase Realtime** + 설비 센서 데이터 직접 연동 파이프라인 구축으로 KPI 지연 최소화.
  - 트렌드 분석에 **이상치 자동 플래깅** 로직 추가. 정상 범위 이탈 시 Slack/이메일 알림 자동 발송.
  - OEE, MTBF, MTTR 등 자동차 부품 제조 핵심 지표를 **표준 대시보드 템플릿**으로 정형화하여 매주 자동 생성.
- **적용 우선순위**: 🔴 Supabase Realtime 연동 → 🟡 이상치 알림 → 🟢 표준 KPI 대시보드

### web-builder
- **개선 제안**:
  - FMS 포털 Next.js 14 앱에 **AI 유지보수 어시스턴트 채팅 위젯** 통합. 기술자가 자연어로 장비 이력, 부품 재고, 정비 절차 조회 가능하도록 구현 (예: Vercel AI SDK + Claude API).
  - 설비 이상 감지 시 **작업지시서 자동 생성 → Supabase 저장 → 담당자 알림** 엔드-투-엔드 플로우 개발.
  - 모바일 현장 접근성 강화: PWA(Progressive Web App) 변환으로 현장 기술자가 스마트폰으로 실시간 정비 지시 확인.
- **적용 우선순위**: 🔴 AI 채팅 위젯 → 🟡 작업지시서 자동화 플로우 → 🟢 PWA 전환

### planner
- **개선 제안**:
  - 신규 기능 명세 작성 시 **A2A 멀티 에이전트 아키텍처** 관점을 반영. 기능별로 담당 에이전트 역할과 데이터 흐름을 명확히 정의하는 Agent Interaction Diagram 표준화.
  - DB 스키마 설계에 **설비 센서 이벤트 로그 테이블** 포함: `equipment_id`, `sensor_type`, `value`, `threshold`, `timestamp`, `alert_flag` 컬럼 구조 표준 제안.
  - UI/UX 설계 시 현장 기술자(저숙련 사용자) 관점의 **모바일 퍼스트 와이어프레임** 원칙 도입.
- **적용 우선순위**: 🔴 센서 이벤트 스키마 표준화 → 🟡 Agent Interaction Diagram → 🟢 모바일 퍼스트 와이어프레임

### evaluator
- **개선 제안**:
  - QA 체크리스트에 **AI 기능 전용 검증 항목** 추가: 모델 응답 정확도, 지연시간(latency), 오류 폴백(fallback) 동작, 민감 정보 노출 여부.
  - 최소 3회 반복 검증 프레임워크를 **자동화 테스트 스크립트(Playwright)**로 전환하여 회귀 테스트 시간 단축.
  - 실제 공장 데이터를 활용한 **Staging 환경 시나리오 테스트**: 센서 이상값, 부품 재고 0, 다중 알림 동시 발생 등 엣지 케이스 커버리지 강화.
- **적용 우선순위**: 🔴 AI 기능 검증 체크리스트 → 🟡 Playwright 자동화 → 🟢 Staging 엣지케이스 시나리오
