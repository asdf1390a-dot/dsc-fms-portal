# AI팀 일일 업그레이드 보고 — 2026-07-05

## 🔍 벤치마킹 인사이트

1. **Agentic AI 제조업 채택 급증**: Deloitte는 2026년까지 제조업 내 Agentic AI 채택이 6%→24%로 4배 증가할 것으로 전망. AI 에이전트가 이상 탐지 → ERP 부품 조회 → 기술자 스케줄링 → 작업 지시서 생성까지 자동화하며, 도입 후 3~6개월 내 ROI 달성이 표준화되고 있음.

2. **멀티 에이전트 협업 아키텍처**: 단일 AI가 아닌 신뢰성 에이전트·유지보수 에이전트·운영 에이전트 간 핸드오프 구조가 Best Practice로 정착. 명확한 소유권과 에스컬레이션 로직이 핵심이며, 이는 FMS 포털의 팀원 역할 분리와 직접 대응됨.

3. **예측 정비 AI 도구의 자동차 부품 분야 성과**: AI 기반 예측 정비가 고정 임계값 모니터링 대비 장애를 30~50% 더 일찍 감지. Tractian, SparkCognition, Fiix 등 선도 플랫폼은 IoT 진동·열화상·음향 센서 융합으로 다운타임을 최대 50% 절감.

4. **Back-Office 워크플로우 통합이 최우선 ROI 영역**: McKinsey 2025 보고서에 따르면 중소 제조업체가 생산 스케줄링·조달·품질관리·고객 주문 간 수동 핸드오프를 자동화할 경우 납기 준수율 18~34% 향상. 공장 현장보다 Back-Office 통합이 더 높은 ROI를 제공.

5. **GenAI 기반 AI 유지보수 어시스턴트 부상**: 2026년 핵심 트렌드는 "디지털 멘토" — 신입 기술자가 질문만으로 공장 전체의 집단 지성에 접근하는 시스템. Fabrico, oxmaint 등이 GenAI를 작업 지시서 생성·장애 진단·기술자 가이던스에 통합하여 도입 첫날부터 시간 절감 효과 발생.

## 🟢 팀원별 업그레이드 제안

### translator
- **개선 제안**:
  - 기술 용어 glossary DB 구축: 본사(한국)↔인도 공장 간 자동차 부품·설비 용어를 Supabase 테이블로 관리하여 번역 일관성 확보
  - AI 번역 후처리 워크플로우 도입: GenAI 초벌 번역 → 전문 용어 glossary 대조 → 담당자 최종 검수 3단계 파이프라인 표준화
  - 긴급 커뮤니케이션 템플릿 라이브러리: 설비 다운·품질 이슈·납기 변경 등 반복 상황별 한↔영 표준 문안 사전 작성
- **적용 우선순위**: 높음 — 본사-인도 소통 오류가 생산 지연으로 직결됨

### data-analyst
- **개선 제안**:
  - KPI 이상 탐지 자동화: Supabase 데이터에 통계적 임계값(±2σ) 기반 알림 설정으로 수동 엑셀 모니터링 대체
  - 트렌드 예측 모델 도입: 생산량·불량률·설비 가동률 시계열 데이터에 ARIMA 또는 Prophet 적용, 주간 예측 보고서 자동 생성
  - 데이터 파이프라인 문서화: CSV→Supabase 업로드 과정의 변환 규칙과 데이터 품질 체크 기준 표준화하여 분석 재현성 확보
- **적용 우선순위**: 높음 — 예측 정비 AI 연계의 데이터 기반 선행 조건

### web-builder
- **개선 제안**:
  - 실시간 설비 상태 대시보드 구현: Next.js 14 Server Actions + Supabase Realtime으로 설비별 가동/정지/경보 상태를 초 단위 갱신
  - AI 어시스턴트 채팅 위젯 통합: FMS 포털 내에 Claude API 기반 유지보수 Q&A 챗봇 삽입, 작업 지시서·매뉴얼 검색 자동화
  - 모바일 최적화 PWA 전환: 현장 기술자가 스마트폰으로 작업 지시 확인·서명·사진 업로드 가능하도록 PWA 기능 추가
- **적용 우선순위**: 중간 — 실시간 대시보드 먼저, 모바일 PWA는 2단계

### planner
- **개선 제안**:
  - 멀티 에이전트 워크플로우 명세: 신뢰성·유지보수·운영 에이전트 간 데이터 핸드오프 흐름을 기능 명세서에 반영, 에스컬레이션 규칙 정의
  - DB 스키마에 예측 정비 데이터 레이어 추가: 센서 로그·장애 이력·부품 교체 기록 테이블 설계로 향후 AI 연동 기반 마련
  - UI/UX 디자인 시스템 표준화: 설비 상태 색상 코드(정상=녹, 경고=황, 이상=적) 및 알림 배지 패턴을 Design Token으로 정의
- **적용 우선순위**: 높음 — 설계 선행 없이는 구현 방향이 흔들림

### evaluator
- **개선 제안**:
  - 자동화 E2E 테스트 도입: Playwright로 FMS 포털 핵심 플로우(로그인→설비 조회→작업 지시 생성→완료 처리) 시나리오 자동화, CI 파이프라인 연동
  - 3회 반복 검증 체크리스트 표준화: 기능 검증(요구사항 충족?) → 통합 검증(타 모듈 영향?) → 회귀 검증(기존 기능 깨짐?) 3단계 형식지 템플릿화
  - AI 출력 품질 평가 기준 마련: 번역 정확도·KPI 분석 신뢰도·AI 어시스턴트 응답 품질 측정 지표와 허용 임계값 정의
- **적용 우선순위**: 높음 — 자동화 테스트 없이는 배포 속도와 품질이 상충
