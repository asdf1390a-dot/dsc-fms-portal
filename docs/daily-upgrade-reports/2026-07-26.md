# AI팀 일일 업그레이드 보고 — 2026-07-26

## 🔍 벤치마킹 인사이트

1. **AI 정비 어시스턴트의 "디지털 멘토" 진화**: 2026년 제조업에서 AI 정비 어시스턴트는 단순 알림 시스템을 넘어 LLM 기반 대화형 인터페이스로 발전. 기술자가 장비 ID와 증상을 입력하면 과거 정비 이력, 부품 매뉴얼, 유사 사례를 종합해 절차를 즉시 제안. 단 산업용 AI는 소비자 AI(95%)와 달리 **99.5% 이상 정확도**가 요구되므로 도입 전 도메인 특화 파인튜닝 필수.

2. **자동차 부품 제조사 OEE 58%→82% 달성 사례**: 실제 중소형 자동차 부품사가 AI 예측 정비 도입 후 OEE 82%, 비계획 가동중단 71% 감소, 생산 용량 $2.9M 회복 달성. 2026년 기준 제조사 중 65%가 AI 예측 정비 구현을 계획 중이며, 일반적 투자 회수 기간은 12~24개월. DSC Mannur도 파일럿 라인 1개로 시작 시 6개월 내 정량 지표 확보 가능.

3. **AI+CMMS 통합 플랫폼이 핵심 차별 요소**: 2026년 최대 기술 격차는 AI 예측 엔진과 CMMS(정비 관리 시스템)가 같은 플랫폼에 있는가 여부. 분리된 경우 AI 경보 → 작업지시서 생성 사이 수동 연결 작업이 발생하여 대응 시간 평균 47분 지연. FMS 포털에서 Supabase를 단일 진실 공급원으로 유지하는 현 아키텍처가 올바른 방향임.

4. **Agentic AI: 12가지 공장 바닥 워크플로우 자동 실행**: 2026년 산업 AI 트렌드는 단일 감지 에이전트에서 다단계 목표를 이해하고 여러 시스템에서 자율 실행하는 Agentic AI로 이동. 자동화 가능 워크플로우: 생산 스케줄 조정, 정비 우선순위 결정, 재고 조율, 불량 플래그 생성, 교대 리포트 작성 등 12개 영역. QAD Redzone은 Hannover Messe 2026에서 실시간 데이터 기반 코칭 권장사항 자동 배포를 시연.

5. **모바일 퍼스트·음성 지원이 현장 정비 속도 30% 개선**: AI 기반 모바일 도구와 음성 어시스턴트가 현장 작업을 간소화 — 수동 데이터 입력 시간 감소, 핸즈프리 지원으로 기술자가 작업 중단 없이 절차 확인 가능. 작업지시서 업데이트를 음성으로 처리 시 완료 시간이 평균 30% 단축됨. FMS 포털 모바일 UX 개선의 ROI 근거로 활용 가능.

## 🟢 팀원별 업그레이드 제안

### translator
- **개선 제안:**
  - LLM 번역 후처리 단계 도입: 자동 번역 결과를 도메인 용어집(전일 구축 제안)과 대조하는 검증 레이어 추가 — 오역률 목표 < 2%
  - 본사 보고용 "KPI 스냅샷 번역 템플릿" 표준화: OEE·MTTR·가동중단 시간 수치가 포함된 주간 요약을 정형 포맷으로 반복 처리
  - 정비 어시스턴트 AI가 생성한 영문 절차서를 현장 기술자용 한국어로 실시간 번역하는 파이프라인 설계 (web-builder와 협업)
- **적용 우선순위:** 🟡 중 — 번역 템플릿 표준화 2일 내 완료 가능, KPI 스냅샷 즉시 적용

### data-analyst
- **개선 제안:**
  - Supabase에 `equipment_oee_daily` 뷰 생성: 장비별 OEE를 일간 집계하고, 목표치(82%) 대비 편차를 자동 플래그 처리하는 쿼리 작성
  - 예측 정비 ROI 추적 대시보드 구성: 비계획 가동중단 빈도×평균 복구 시간(MTTR) → 비용 환산 공식 적용, 누적 절감액 시각화
  - CSV/Excel 업로드 이상값 탐지 강화: IQR 기반 플래그 처리에 더해 "전주 동일 교대 대비 ±30% 초과" 규칙 추가하여 생산 이상 조기 감지
- **적용 우선순위:** 🔴 높음 — `equipment_oee_daily` 뷰가 DSC Mannur 파일럿 ROI 증명의 핵심 데이터 소스

### web-builder
- **개선 제안:**
  - 음성 메모 작업지시서 기능 구현: 현장 기술자가 스마트폰 마이크로 음성 녹음 → Web Speech API로 텍스트 변환 → 작업지시서 초안 자동 생성 (Next.js 14 + Supabase)
  - 장비 상태 페이지에 "AI 진단 제안" 패널 추가: 장비 ID + 최근 오류 코드 조합으로 LLM API 호출 → 정비 절차 초안을 UI에 즉시 표시
  - PWA(Progressive Web App) 전환 검토: 오프라인 작업지시서 캐싱 + 푸시 알림 지원으로 현장 연결 불안정 환경 대응
- **적용 우선순위:** 🔴 높음 — 음성 메모 기능은 구현 난이도 낮고 현장 채택률 즉각 향상 예상

### planner
- **개선 제안:**
  - AI+CMMS 통합 아키텍처 명세서 v1.0 작성: FMS 포털 내 예측 정비 엔진 → 작업지시서 자동 생성 → 완료 확인 → KPI 반영까지 전체 플로우 다이어그램 완성
  - 신규 `equipment_alerts` 테이블 스키마 설계: `alert_id`, `equipment_id`, `severity(1-5)`, `predicted_failure_at`, `auto_work_order_id`, `ack_at`, `resolved_at` 컬럼 포함
  - Agentic 워크플로우 우선순위 결정 프레임워크 도입: 신기능 명세 시 "측정 가능 지표 + 데이터 충분성 + 팀 소유권" 3가지 조건 충족 여부를 명시
- **적용 우선순위:** 🟡 중 — `equipment_alerts` 스키마는 web-builder 다음 스프린트 전 완성 필요

### evaluator
- **개선 제안:**
  - 산업용 AI 정확도 기준 99.5% 적용: 기존 3회 반복 검증에 "오탐 비율 < 0.5%" 정량 합격 기준 추가, 불합격 시 자동 재검증 트리거
  - 모바일 UX 검증 체크리스트 신설: 실제 스마트폰(iOS/Android)에서 작업지시서 생성·완료·서명 플로우를 반드시 1회 이상 실기 테스트
  - QA 로그 자동화 강화: Supabase `qa_logs` 테이블에 검증 항목·합격 기준·결과·소요 시간을 자동 기록, 주간 오탐률 트렌드 리포트 생성
- **적용 우선순위:** 🟡 중 — 99.5% 정확도 기준 즉시 적용, 모바일 체크리스트는 web-builder 배포 시점에 맞춰 준비
