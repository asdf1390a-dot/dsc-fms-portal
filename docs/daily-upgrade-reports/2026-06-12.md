# AI팀 일일 업그레이드 보고 — 2026-06-12

## 🔍 벤치마킹 인사이트

1. **생성AI가 희귀 고장 시나리오를 스스로 생성** — 전통적 ML 모델의 최대 약점인 "데이터 부족"을 생성AI가 돌파. 실제 발생하지 않은 고장 시나리오에 대한 합성 데이터셋을 자동 생성해 이상 감지 정확도를 획기적으로 향상. DSC Mannur처럼 특정 설비 고장 이력이 적은 공장에서 특히 유효한 접근법.

2. **예측정비 시장 CAGR 30.5% — 2026년 $28.24B 돌파 예상** — 2025년 $14.31B에서 1년 만에 두 배 규모로 성장. 자동차 부품 제조사 47%가 이미 예측정비 기술을 도입 중이며, AI 예측정비 도입 시 비계획 다운타임 최대 50% 감소, 예비부품 재고 22% 절감 효과 실증. FMS 포털의 정비 이력 데이터가 곧 핵심 경쟁 자산이 됨.

3. **AI 에이전트 거버넌스: 물리 설비 제어는 별도 안전 프로토콜 필수** — AI 에이전트가 실시간으로 작업 일정을 재조정하고 정비를 자율 트리거하는 수준에 도달. IBM·Salesforce 모두 "물리 장비를 제어하는 에이전트는 일반 소프트웨어 에이전트와 다른 안전 계층이 필요"를 강조. FMS 포털이 자동 발주·작업지시 기능으로 확장될 때 Human-in-the-loop 승인 플로우 설계가 선결 과제.

4. **하이퍼오토메이션: 노코드 플랫폼이 커스텀 개발 수준에 도달** — 2026년 노코드 AI 워크플로우 빌더는 자연어 입력만으로 자동화 파이프라인을 수 시간 내 구축. UiPath·Power Automate·Automation Anywhere가 AI, RPA, API 통합, 분석을 단일 환경에 통합. FMS 포털 내 반복 보고서 작성·KPI 알림·이메일 발송 루틴을 노코드 자동화로 빠르게 구현 가능.

5. **디지털 트윈이 공장 의사결정의 표준 도구로 정착** — 실시간 센서 데이터로 공급되는 공장 가상 복제본을 통해 생산 변경을 "실제 라인 중단 없이" 시뮬레이션. 병목 구간 사전 식별 및 "what-if" 시나리오 분석이 일상화됨. DSC Mannur FMS 포털에서 설비별 가동률 시계열 누적이 장기적으로 디지털 트윈의 데이터 기반이 됨.

## 🟢 팀원별 업그레이드 제안

### translator
- **개선 제안:**
  - 자동차 부품 제조 도메인 특화 한↔영 용어 매핑 테이블을 Supabase 테이블로 관리. AI 번역 시 이 테이블을 context로 주입해 "설비 명칭·공정 용어·품질 기준값" 오역률 최소화.
  - 생성AI의 합성 데이터 관련 개념처럼 신규 기술 용어가 빠르게 등장하는 추세를 반영해, 월 1회 용어집 갱신 루틴을 evaluator 검증과 연계해 정례화.
  - 본사 보고서의 수치·단위(ppm, MPa, kgf 등) 포함 문장은 번역 후 원문 수치와 자동 대조 스크립트 적용하여 수치 오역 제로 목표 설정.
- **적용 우선순위:** 🔴 즉시 — Supabase 용어 테이블 스키마 설계 + MVP 50개 핵심 용어 등록 (1주 이내)

### data-analyst
- **개선 제안:**
  - 예측정비 ROI 측정을 위한 핵심 지표 3종 신설: ① 비계획 다운타임 발생 건수/시간, ② 예비부품 긴급 조달 빈도 및 비용, ③ 정비 공수 대비 예방 성공률. Supabase에서 자동 집계 후 주간 트렌드 차트로 web-builder에 제공.
  - 합성 데이터 생성 기법 학습 검토 — 설비 고장 데이터가 희소한 구간에 대해 통계 기반 augmentation을 적용해 예측 모델 학습 데이터 품질 향상.
  - 노코드 AI 워크플로우 도구(Power Automate 또는 n8n) 파일럿 적용: 주간 KPI 리포트 자동 생성·이메일 발송 루틴을 코드 없이 구현해 반복 분석 공수 50% 절감 목표.
- **적용 우선순위:** 🟡 단기 — ROI 지표 3종 Supabase 뷰 구현 (2주), 노코드 KPI 리포트 파일럿 (1개월)

### web-builder
- **개선 제안:**
  - FMS 포털에 Human-in-the-loop 승인 UI 패턴 도입: AI가 자동 제안한 작업지시서·부품 발주 등을 관리자가 원클릭 승인/거절할 수 있는 "AI 제안 패널" 컴포넌트 설계. 물리 설비 연동 전 안전 필터 역할.
  - Supabase Realtime을 활용한 설비 이상 알림 배지(badge) 시스템 구현: 고장 감지 시 헤더 아이콘에 실시간 카운터 표시 → 알림 클릭 시 해당 설비 상세 페이지로 바로 이동.
  - 노코드 트렌드에 대응한 관리자용 "리포트 빌더" 기능 검토 — 비개발자 관리자가 드래그앤드롭으로 KPI 대시보드 레이아웃을 커스터마이징할 수 있는 UI (React Grid Layout 등 활용).
- **적용 우선순위:** 🟡 단기 — Realtime 알림 배지 (1주), Human-in-the-loop 승인 UI (3주), 리포트 빌더 (1분기)

### planner
- **개선 제안:**
  - 디지털 트윈 로드맵 수립: FMS 포털 DB에 누적되는 설비 가동 데이터를 기반으로 6개월~1년 후 디지털 트윈 파일럿 범위를 사전 정의. 지금부터 설비ID·타임스탬프·센서값 스키마를 트윈 친화적으로 설계하면 나중에 재공사 불필요.
  - 기능 명세서에 "에이전트 안전 등급" 항목 추가: 해당 기능이 물리 설비에 영향을 주는지(HIGH), 데이터만 처리하는지(LOW)를 명시해 web-builder와 evaluator가 적절한 검증 깊이를 자동으로 인지하도록 규격화.
  - 노코드 자동화 통합 포인트 식별: 매주 반복되는 보고서 생성·알림 발송·데이터 동기화 흐름 중 코드 개발 없이 Power Automate/n8n으로 대체 가능한 항목을 목록화해 web-builder 개발 부담 경감.
- **적용 우선순위:** 🟡 단기 — 디지털 트윈 친화 스키마 가이드 초안 (2주), 에이전트 안전 등급 명세 항목 추가 (즉시)

### evaluator
- **개선 제안:**
  - 합성 데이터 및 AI 생성 콘텐츠(번역문·분석 보고서·작업지시서) 대상 전용 검증 체크리스트 작성: 수치 정확성, 인과관계 왜곡 여부, 현장 적용 가능성 3개 축으로 최소 3회 반복 검증 수행.
  - Human-in-the-loop 승인 플로우 QA 시나리오 정의: AI 제안이 잘못된 경우(오탐·과소탐지) 관리자가 거절했을 때 시스템이 올바르게 처리하는지 엣지 케이스 테스트 스크립트 작성.
  - 인도 첸나이 공장 환경 특화 성능 QA: 현지 네트워크 변동성 조건에서 Realtime 알림 지연 시간 측정 기준치(목표 3초 이내) 수립 및 주간 자동 측정 스크립트 도입.
- **적용 우선순위:** 🔴 즉시 — AI 생성 콘텐츠 검증 체크리스트 v1 작성 (3일 이내), 네트워크 성능 측정 스크립트 (2주)

## 💡 오늘의 효율화 제안

1. **"에이전트 안전 등급" 제도 팀 전체 도입** — planner가 명세에 안전 등급(물리 설비 영향 여부)을 표기하면, web-builder는 HIGH 등급 기능에 반드시 Human-in-the-loop UI를 포함하고, evaluator는 HIGH 등급 기능에 추가 QA 사이클을 자동 적용하는 3자 연계 프로세스 수립. 현재 AI 에이전트 거버넌스의 가장 큰 리스크인 "물리 시스템 오작동"을 팀 레벨에서 선제 차단할 수 있음.

2. **노코드 자동화 파일럿 우선 적용 대상 선정 (이번 주 내)** — translator의 주간 번역 보고서 발송, data-analyst의 KPI 리포트 이메일 발송, evaluator의 QA 결과 Slack 알림 중 가장 반복적인 1개를 골라 n8n 또는 Power Automate로 먼저 자동화. 2026년 트렌드인 노코드 AI 워크플로우를 팀이 직접 체험하면 FMS 포털 내 자동화 기능 명세의 실현 가능성 판단 능력도 동시에 향상됨.
