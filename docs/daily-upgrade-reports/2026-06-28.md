1. **Agentic AI 제조업 채택 4배 급증** — Deloitte 예측에 따르면 2026년 제조업 agentic AI 채택률이 6%→24%로 4배 증가. 단순 알림 수준을 넘어 AI가 정비 일정 자동 수립·부품 발주·작업지시서(WO) 생성까지 자율 처리하는 단계로 진입.

2. **AI 유지보수 어시스턴트 = "디지털 멘토"** — 현장 기술자가 자연어로 공장 집단지성에 질의하는 "Maintenance Copilot" 패러다임이 2026년 주류. Fabrico·Oxmaint 등 플랫폼에서 3~6개월 내 ROI 실현 사례 증가.

3. **자동차 부품 예지정비 시장 $16.75B 전망(2030)** — Tractian·UpKeep Nova AI 등 도구가 진동·온도·전력 소비 센서 데이터를 실시간 분석, 부품 고장을 조기 감지. AI 비전(UVeye·Bosch)은 5분 이내 360° 설비 점검 자동화.

4. **제조업체 98%가 AI 탐색 중, 단 20%만 실전 준비 완료** — 대다수 제조사가 워크플로우 파편화·수작업 예외처리에 발목. SMB 기준 연간 $340K 손실이 스케줄링 오류·공급업체 커뮤니케이션 지연에서 발생.

5. **워크플로우 자동화로 납기 준수율 18~34% 개선** (McKinsey 2025 제조업 운영 보고서) — 생산 스케줄링↔조달↔품질관리↔주문관리 간 수작업 핸드오프가 최대 병목. MCP(Model Context Protocol) + A2A(Agent-to-Agent) 조합이 레거시 시스템 연동 표준으로 부상.

  - 긴급 정비 지시나 안전 알림은 번역 즉시 Slack/카카오 알림 연동 파이프라인 구성
- **적용 우선순위:** 🔴 용어집 DB 구축 → 🟡 알림 파이프라인 → 🟢 문화 보정 레이어

### data-analyst
- **개선 제안:**
  - 현재 Excel/CSV 수작업 KPI 집계를 Supabase Edge Function + cron으로 자동화 (일/주/월별 자동 리포트 생성)
  - 설비 센서 데이터 이상 감지를 위한 간단한 통계적 이상치 탐지 쿼리 추가 (Z-score 또는 IQR 기반)
  - 예지정비 플랫폼(Tractian/UpKeep 등) API 연동 검토 — 기존 Supabase KPI 대시보드와 통합
- **적용 우선순위:** 🔴 자동화 cron 리포트 → 🟡 이상치 탐지 쿼리 → 🟢 외부 API 연동

### web-builder

  - FMS 포털 내 AI 유지보수 어시스턴트 채팅 위젯 추가 — 기술자가 설비 ID를 입력하면 정비 이력·부품 재고 현황을 자연어로 조회

- **적용 우선순위:** 🔴 WO 자동생성 플로우 → 🟡 채팅 위젯 → 🟢 Edge Runtime 최적화
